# Build-a-feature prompt skeleton

Fill the <angle brackets>, paste into Claude Code. One prompt = one outcome.

```
Goal: <one sentence>

Context: repo <name>, stack <stack>, used by <who> on <device>.

Steps:
1. <smallest useful step>
2. <next step>
3. <next step>

Rules: work on a new branch; no secrets in code; parameterised SQL only; no innerHTML; keep tests passing and add a test for new logic; never push to main.

Done when: <testable check 1>; <testable check 2>.

Close: explain what you did in simple words, give me the preview URL and exactly what to check.
```
